# Install profile matching the reference video

1. Open https://github.com/VamshiGVR/VamshiGVR
2. Upload README.md, assets/header.svg, assets/footer.svg and .github/workflows/snake.yml keeping the exact paths. Use Add file > Upload files, or clone and push with Git.
3. Commit to the default branch. GitHub renders the profile README automatically.
4. Go to repository Settings > Actions > General and ensure workflow permissions allow the action to write to the repository. If needed select Read and write permissions.
5. Open Actions > Pink contribution snake > Run workflow. After successful completion the output branch should contain the animated snake SVG.
6. Replace the placeholder image in the About Me table with your own portrait/illustration if desired.

Notes:
- Header/footer are designed locally and render natively on GitHub. Typing animation, technology icons and statistics depend on third-party image services and may sometimes be unavailable or rate-limited.
- The sample tech icons include broad skills; remove any you don't want to claim.
- GitHub profile sidebars and pinned repositories cannot be styled by a README. This recreates the styled README portion shown in the reference video.
- Contributor chart and streak totals are live, not made-up numbers.
